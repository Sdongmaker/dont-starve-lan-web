# 🔥 荒野余烬 · 局域网饥荒联机版 (Don't Starve LAN Web)

一款**零外部依赖、纯离线局域网即开即玩**的多人网页生存游戏，深度还原《饥荒联机版 (Don't Starve Together)》核心生存乐趣。

## 🚀 快速启动与局域网联机方法

### 1. 房主电脑启动服务
确保已安装 [Node.js](https://nodejs.org/)（无需 `npm install`，零第三方依赖）：
- **方式一（推荐）**：直接双击运行根目录下的 **`启动局域网服务器.bat`**
- **方式二（命令行）**：
  ```bash
  npm start
  ```

### 2. 局域网好友加入游戏
1. 启动后，控制台和网页大厅右上角会自动显示本机局域网地址（例如 `http://192.168.1.x:3000`）。
2. 同一 Wi-Fi / 局域网下的电脑或平板打开浏览器访问该地址即可进入大厅！
3. 一人点击 **【✨ 创建新世界】**（或 **【📂 读取历史存档】**），其他人点击房间右侧 **【立即加入】** 即可同屏合作求生！

> **💡 局域网连不上排查提示**：首次运行若弹出 Windows 防火墙提示，请勾选“专用网络 + 公用网络”并点击**允许访问**。
